# AWS Architecture Icons

These SVG files are unmodified copies from the AWS Architecture Icons package
`Icon-package_07312026` (released 2026-07-31), downloaded on 2026-11-06 from
https://aws.amazon.com/architecture/icons/.

AWS states there that customers and partners may use these toolkits and assets to create
architecture diagrams. They are used here only inside architecture diagrams. AWS and the service
names are trademarks of Amazon.com, Inc. or its affiliates.

Files are renamed for readability; their content is unchanged.
